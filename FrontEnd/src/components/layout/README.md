# components/layout

The frame around every dashboard page. The look is in `../../../DESIGN.md` (part 4, "The app shell").

- **Desk and sheet:** warm grey page, one white sheet on it.
- **Rail (sidebar):** a narrow icon rail. Home, Profile, Review (with a badge: how many items wait), Jobs. Built with the shadcn Sidebar piece (`collapsible="icon"`).
- **Top bar:** page title on the left, page actions on the right, then a round avatar with my initials.

No light/dark switch (the look is light only). No user menu (there is no login).
